# Checklist de lançamento — Eletronic

Siga em ordem. Os passos marcados com 👤 você faz (exigem sua conta ou pagamento). Os marcados com 🤖 eu já deixei pronto no site.

## 1. Domínio próprio 👤
- [ ] Escolher o nome (sugestões: `eletronic.com.br`, `eletronictaubate.com.br`).
- [ ] Comprar em registro.br (~R$ 40/ano para `.com.br`) ou outro registrador.
- [ ] No Netlify: *Site configuration → Domain management → Add a domain* com o nome novo.
- [ ] No registrador: colar os registros DNS que o Netlify mostrar (A e CNAME).
- [ ] Ativar HTTPS (o Netlify faz sozinho depois que o DNS propaga).
- [ ] Avisar o Claude para trocar o endereço em todo o site (canonical, og, schema, sitemap, manual).

## 2. Google Meu Negócio 👤
- [ ] Criar o perfil em https://business.google.com com a conta da loja.
- [ ] Nome: Eletronic. Categoria: Loja de celulares. Endereço: R. Dr. Souza Alves, 384 – Centro, Taubaté/SP.
- [ ] Telefone: (12) 99746-3135. Site: o domínio final.
- [ ] Verificar o perfil (código por carta ou telefone). Sem isso não aparece na busca.
- [ ] Depois de verificado: escrever as primeiras fotos da loja e dos aparelhos.

## 3. Search Console 👤
- [ ] Entrar em https://search.google.com/search-console com a conta da loja.
- [ ] Adicionar a propriedade com o domínio final.
- [ ] Enviar o `sitemap.xml`.
- [ ] Pedir indexação da página inicial (URL Inspection → Solicitar indexação).

## 4. Conferir antes de divulgar 🤖
- [ ] `robots.txt` e `sitemap.xml` acessíveis.
- [ ] Título, descrição e imagem de compartilhamento corretos (testar o link no WhatsApp).
- [ ] Testar o agendamento e o acompanhamento de pedido em um celular de verdade.
- [ ] Confirmar no painel que os aparelhos reais estão "no site".

## 5. Divulgar 👤
- [ ] Colocar o link do site na bio do Instagram (@eletronic.oficial).
- [ ] Enviar o link do Google Meu Negócio para os clientes que já compraram, pedindo avaliação.
- [ ] Usar o botão "Pedir avaliação" da aba Pedidos depois de cada entrega.
